
# TAHAP 6 — `06_webgis.ipynb` + Streamlit

## 6.1 WebGIS di dalam notebook (WAJIB)

WebGIS **harus tampil sebagai output cell notebook** (peta Folium/Leaflet), karena proyek ini menyajikan proses lewat Jupyter Book (web statis). Isi peta:

- Basemap satelit: **Esri World Imagery** sebagai default; **Google Satellite** (`https://mt1.google.com/vt/lyrs=s&x={x}&y={y}&z={z}`) sebagai opsi. Tulis catatan: itu tile XYZ (bukan WMS standar), tile Google memiliki batasan ketentuan layanan, dan basemap hanya referensi visual, **bukan data training**.
- Overlay `klasifikasi_jawa_timur.tif`: reproyeksi ke EPSG:4326, buat PNG RGBA berwarna per kelas (nodata transparan), **downsampled** dengan metode yang cocok untuk data kategorikal (jelaskan trade-off resolusi vs ukuran; laporkan dimensi PNG dan ukuran file).
- Boundary Jawa Timur (sederhanakan geometri bila perlu dan laporkan toleransi/ukuran).
- `LayerControl`, **legenda 6 kelas**, dan kontrol **opacity berbasis JavaScript di dalam HTML peta**. Jangan memakai `ipywidgets`, karena tidak berfungsi pada Jupyter Book statis.
- Tampilkan peta langsung di notebook (output tersimpan di `.ipynb`), dan tabel luas per kelas di bawahnya dari CSV Tahap 5.
- Pastikan peta tetap tampil di Jupyter Book: notebook sudah ter-eksekusi, `execute_notebooks: off`, laporkan ukuran file `.ipynb` dan jaga di bawah batas 100 MB GitHub (kurangi resolusi overlay bila perlu).

## 6.2 Analisis kebijakan (dibatasi pada data)

- Luas dan persentase per kelas (hektar).
- **Per kabupaten/kota HANYA jika** boundary level kabupaten/kota benar-benar ada di `boundary_jatim.geojson` (hasil pemeriksaan 2.2). Jika tidak, tulis "tidak tersedia" dan jangan mengunduh.
- Interpretasi untuk tata ruang dan kebijakan (mis. sawah vs permukiman, mangrove pesisir, perairan darat) dengan catatan wajib: satu snapshot tidak menunjukkan perubahan lahan; akurasi mengikuti label sumber sekunder; tidak ada klaim kausal; 6 kelas adalah penyederhanaan dari acuan SNI/KLHK.

## 6.3 Streamlit (`app.py`, pelengkap)

Streamlit + streamlit-folium, membaca hasil dari file Tahap 5 (bukan angka hardcode): peta (toggle basemap, opacity, legenda), tabel luas per kelas, metrik model dan confusion matrix, halaman metodologi (ringkasan data, provenance, keterbatasan, jumlah polygon valid/terpilih). Gunakan overlay PNG/COG yang ringan. Tampilkan peringatan bila ada file > 100 MB (sarankan Git LFS atau versi reduksi). Buat `requirements.txt` dan petunjuk deploy ke Streamlit Community Cloud. **Jangan mengklaim aplikasi sudah online** jika belum di-deploy.

## 6.4 Jupyter Book (web statis)

- `_toc.yml`: keenam notebook + halaman "Deployment" (tautan/instruksi Streamlit).
- `_config.yml`: `execute_notebooks: off` (atau `cache`), `exclude_patterns` untuk file besar (`*.tif`, data mentah, model).
- Proses (Bab 1–5) dan WebGIS (notebook 06) tampil di web statis.

**Checkpoint Tahap 6:** peta tampil sebagai output di notebook 06 yang sudah ter-eksekusi; ukuran `.ipynb` dilaporkan; `app.py` dan `requirements.txt` ada; `_toc.yml` dan `_config.yml` diperbarui.
