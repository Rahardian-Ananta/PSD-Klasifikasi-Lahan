# TAHAP 5 — `05_evaluation.ipynb` (BAB 5)

**5.1 Evaluasi semua model pada test set masing-masing** (dipakai sekali setelah pemilihan di CV): accuracy, **macro-F1**, weighted-F1, precision/recall/F1 per kelas dan macro, classification report, confusion matrix per model (nama kelas: Sawah, Bangunan / Permukiman, Mangrove, Lahan hijau, Laut, Danau). Evaluasi juga pada **level polygon** agar adil (pixel-based diagregasi voting), karena pixel dalam satu polygon berkorelasi. Evaluasi semua model juga pada pixel test, karena peta akhir diprediksi per pixel.

**5.2 Cara membaca confusion matrix:** baris = kelas sebenarnya, kolom = prediksi, diagonal = benar, di luar diagonal = kesalahan spesifik. Jelaskan precision vs recall dari matriks dan pasangan kelas yang paling sering tertukar, berdasarkan hasil aktual.

**5.3 Perbandingan model.** Tabel `model | metode | accuracy | precision_macro | recall_macro | f1_macro` (+ hasil CV) dari hasil eksekusi.

**5.4 Eksperimen jumlah data (learning curve).** Subsampling polygon dari training yang ada (mis. 25%, 50%, 75%, 100% polygon per kelas), beberapa seed (jumlah seed = konfigurasi), test set SAMA, tanpa data baru. Plot macro-F1 vs jumlah polygon untuk kedua metode dan model terpilih; jelaskan apakah kurva mendatar atau masih naik, dan kaitkan dengan batas 50 polygon per kelas.

**5.5 Pemilihan model terbaik (jangan bias).**
- Pilih berdasarkan **macro-F1 hasil CV** (4.4), lalu laporkan hasil test sebagai konfirmasi. Jelaskan alasannya, termasuk bila selisih antar model kecil (laporkan std antar fold dan selang ketidakpastian).
- Jangan menyatakan pixel-based atau polygon-mean "lebih bagus" sebelum melihat hasil; bila lebih baik, katakan **berdasarkan metrik tertentu**; bila hampir sama, katakan hampir sama; bila ada trade-off, jelaskan. Jangan memaksakan pemenang, jangan memilih dari satu angka.
- **Catatan metodologis:** peta akhir dihasilkan per pixel. Bila pemenang adalah model polygon-mean, menerapkannya ke pixel individual adalah pergeseran distribusi (dilatih pada rata-rata). Dokumentasikan ini secara eksplisit, tunjukkan metrik pixel-test model tersebut, dan jangan disembunyikan.

**5.6 Klasifikasi seluruh Sentinel-2.** Input `s2_jatim.tif`; per window/blok ambil 6 band, hitung feature tambahan dengan **urutan identik training**, prediksi `class_id` hanya untuk pixel valid (nodata TIDAK diprediksi), jelaskan penanganan NaN/inf pada indeks. Output `klasifikasi_jawa_timur.tif` (uint8, nodata=0, kompresi, tiled) dengan CRS/transform/width/height/bounds/resolusi sama dengan input. Kelas: 1 Sawah, 2 Bangunan / Permukiman, 3 Mangrove, 4 Lahan hijau, 5 Laut, 6 Danau. Preprocessing harus sama dengan metadata model.

**5.7 Validasi output raster.** Buka ulang file hasil dan tampilkan: CRS, width, height, transform, bounds, nodata, unique values, jumlah pixel tiap kelas; bandingkan dengan input. Bila muncul nilai selain 1–6 dan nodata, **investigasi dan perbaiki pipeline**.

**5.8 Luas per kelas.** `luas_ha = jumlah pixel × luas pixel aktual dari transform/CRS`. Bila raster EPSG:4326, hitung luas pixel dengan benar (jangan asumsikan 100 m²). Tabel `class_id | class_name | pixel_count | luas_ha | persen`; simpan CSV.

**5.9 Visualisasi hasil.** RGB Sentinel-2, hasil klasifikasi, boundary Jatim, legenda 6 kelas, side-by-side RGB vs klasifikasi untuk beberapa zoom (pesisir, kota, danau/waduk, sawah). Nyatakan bahwa ini **pemeriksaan visual, bukan validasi akurasi**. Catat artefak yang terlihat (batas pantai, awan/sisa awan, mixed pixel, garis tile/mosaik) dan bahwa semua pixel dipaksa masuk ke salah satu dari 6 kelas (tutupan lain seperti tambak, hutan, lahan terbuka, awan tidak punya kelas sendiri).

**5.10 Kesimpulan** (hanya dari hasil aktual): model terpilih dan alasannya, kelas yang sulit dibedakan, keterbatasan (label sekunder, beda tahun/musim, satu snapshot beberapa hari, data kecil 50 polygon per kelas, test set kecil), langkah lanjutan.
