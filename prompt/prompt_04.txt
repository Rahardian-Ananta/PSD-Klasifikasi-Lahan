# TAHAP 4 — `04_modeling.ipynb` (BAB 4)

Tugas meminta "gunakan model lain yang menghasilkan akurasi paling tinggi", jadi **jangan hanya Random Forest**.

**4.1 Mulai dari hasil Tahap 3.** Baca CSV hasil Tahap 3 (jangan hitung ulang sembarangan). Tampilkan jumlah polygon, kelas, pixel, sample mean, daftar feature, polygon yang dibuang.

**4.2 Penjelasan model dari konsep sederhana.** Jangan langsung `model.fit(...)`. Jelaskan: feature → decision tree → banyak tree (bagging, random subset fitur) → voting → prediksi kelas, memakai data kecil bertanda **CONTOH ILUSTRASI — bukan data project**, terpisah tegas dari **DATA AKTUAL PROJECT**. Jelaskan singkat dan netral model lain: ExtraTrees, gradient boosting (HistGradientBoosting/LightGBM/XGBoost, sesuai yang tersedia), SVM RBF (perlu scaling); kelebihan/kekurangan masing-masing. Logistic Regression boleh sebagai baseline.

**4.3 Matriks eksperimen:** **{pixel-based, polygon-mean} × {Random Forest, ExtraTrees, gradient boosting, SVM (RBF)}** (+ model lain bila relevan). Perlakuan **setara**:
- feature set sama, split sama (FID sama), metrik sama;
- tuning hanya **GroupKFold (group = FID)** atau StratifiedGroupKFold (`random_state=42`) pada training, ruang pencarian sebanding antar model; jangan memilih hyperparameter dari test set;
- SVM memakai pipeline dengan scaler yang di-*fit* hanya di training/fold; model tree tanpa scaling;
- dengan data kecil (≤ 500 pixel per polygon), subsampling tambahan biasanya tidak diperlukan; jika tetap dilakukan untuk model mahal, subsample hanya di TRAINING, seed tetap, laporkan jumlah sebelum/sesudah dan aturannya, dan terapkan konsisten;
- untuk tiap model tampilkan: jumlah training sample, testing sample, jumlah feature, distribusi kelas, parameter akhir, waktu training;
- simpan semua model dan hasil CV.

**4.4 Ukuran CV (ditetapkan SEBELUM melihat hasil).** Metrik pemilihan utama: **macro-F1 pada level polygon** dari GroupKFold CV (pixel-based diagregasi per polygon dengan voting/rata-rata probabilitas, polygon-mean langsung), supaya unit evaluasi kedua metode sama. Metrik level pixel dilaporkan sebagai tambahan. Laporkan mean ± std antar fold. Catat bahwa tiap fold sangat kecil (mis. beberapa polygon per kelas).

**4.5 Simpan model.** Model terbaik keseluruhan → `best_model.pkl`; Random Forest terbaik → `random_forest_best.pkl` (bila pemenang adalah RF, nyatakan keduanya sama). Metadata JSON: model, feature names (urutan), class mapping, metode (pixel/mean), parameter, `random_state`, preprocessing (scaler, penanganan nodata, rumus indeks, aturan seleksi pixel, cap 500, definisi indeks pada mean), versi library, tanggal/waktu eksperimen.

**Checkpoint Tahap 4:** semua kombinasi terlatih (atau dilewati dengan alasan tertulis), hasil CV tersimpan, tidak ada tuning memakai test set.
